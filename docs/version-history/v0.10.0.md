## Purpose

Experiment with message-level branch controls that feel closer to the native ChatGPT conversation interface than the current single global branch navigator.

## User-visible changes

At each branch fork exposed by the provider response, the export now shows local previous/next controls and a position indicator such as `2/2`. Separate fork points remain independent, so an edited prompt and a regenerated response below it can each be navigated without flattening them into one global branch list. The export remains offline-only and retains the no-JavaScript readable fallback.

## Limitations and decision

This is intentionally a focused experiment. The first implementation should make the local navigation model understandable before adding more controls or attempting to reproduce every native action. Provider tree shapes are undocumented, so unsupported or ambiguous fork structures must remain readable and must not be silently misrepresented.
