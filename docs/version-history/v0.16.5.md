## Purpose

The product owner reported that the side navigation in exports does not work for some
prompts, mostly near the bottom, and asked for a bigger rail with up and down arrows. The
owner also parked the Claude 404 that v0.16.4 did not fix (recorded in
`.claude/context/LOG.md`).

Both navigation faults reproduce in Chromium on fixture exports:

- **Prompts in a version not on screen.** An **All branches** export lists every
  version's prompts on the rail, but only one version of each fork is shown. A hidden
  prompt has no layout, so its link did nothing. A synthetic 30-prompt Claude chat with a
  five-prompt alternative version had five dead ticks.
- **The last prompts.** The rail lights the first prompt inside a band near the top of
  the window. Prompts near the end of a page can never reach that band, so clicking one
  lit an earlier tick. In `long-conversation.json`, clicking ticks 3 and 4 lit tick 2.

v0.16.5:

- switches the fork (or branch view) holding a chosen prompt to that prompt's version
  before scrolling, and draws hidden prompts' ticks fainter;
- keeps the chosen tick lit while its prompt is on screen, and at the end of the page
  lights the last prompt on screen; scrolling with the wheel or by touch releases the
  choice;
- adds ▲ and ▼ buttons above and below the ticks for the previous and next prompt, which
  skip hidden versions and grey out at either end; `j`/`k` do the same;
- makes the ticks longer and thicker and their click area larger.
