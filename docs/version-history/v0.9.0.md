## Purpose

Extend the local exporter to support specific ChatGPT conversations opened inside Projects and provide an optional way to preserve edited prompts and regenerated responses.

## User-visible changes

ChatGPT Projects conversations use the verified `/g/<project>/c/<conversation>` route. Current-branch export remains the default. Users can optionally export all available ChatGPT or Claude.ai branch paths, with branch labels, offline previous/next navigation, and a readable no-JavaScript fallback. ChatGPT image selection remains privacy-first across branch exports.

## Limitations and decision

All-branch export uses complete leaf-to-root paths and can repeat shared prefixes. The next branch-navigation experiment should move toward message-level controls that mimic the native ChatGPT interface rather than relying only on one global branch navigator.
