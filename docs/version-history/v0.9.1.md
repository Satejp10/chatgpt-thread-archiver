## Purpose

Restore the interactive controls in exported offline HTML after a malformed selector prevented the shared inline script from parsing.

## User-visible changes

Dark mode, Copy, branch navigation, and prompt-rail controls now initialize and operate together. The artifact version was bumped to v0.9.1, and the regression suite now compiles the generated inline script so a syntax error cannot silently disable all offline controls again.

## Limitations and decision

Existing HTML exports retain the script that was embedded when they were created; users must create a new export after installing v0.9.1. The next feature experiment is message-level native-style branch navigation.
